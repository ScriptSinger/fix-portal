# Удаление пользователя

При удалении пользователя сервис сначала определяет его вопросы и комментарии,
а также все ответы, которые затронут каскады базы. Он снимает связи изображений
и удаляет полиморфные реакции и комментарии к вопросам. Строки ответов и остальные
связи, для которых есть внешние ключи, удаляются каскадом базы.

Задание `CleanupDeletedUserImages` записывается в таблицу `jobs` в той же транзакции,
что удаление пользователя. Очередь `database` должна использовать то же соединение,
что и данные. После commit воркер проверяет оставшиеся связи и удаляет только
неиспользуемые файлы; сбои хранилища приводят к повтору задания. Для работы нужен
активированный реестр изображений (`images:index --activate`).

Обычное и массовое удаление MoonShine вызывают сервис через модель пользователя;
команда `users:prune-unverified` повторно проверяет каждого кандидата под блокировкой.
Массовый SQL `DELETE` или `User::query()->delete()` обходят сервис и не должны
использоваться для удаления пользователей.
