# Аудит хлебных крошек

Дата: 2026-10-25. Метод: обход 16 типов страниц локальной копии, чтение того, что реально отдаёт сервер (видимые крошки, JSON-LD, microdata,
положение в вёрстке), сверка с боевым ufamasters.ru и с практиками Google и Яндекса. Правок в код этим документом не внесено.

## 1. Что есть сейчас

| Страница | Крошки сейчас | Где стоят |
|---|---|---|
| Лента `/articles` | нет | |
| Статья | Статьи › Категории › **Категория** (последняя ссылка, самой статьи в цепочке нет) | внутри белой карточки, над h1 |
| Категории | Статьи › Категории | в чёрной полосе, над h1 |
| Категория | Статьи › Категории › Категория | чёрная полоса |
| Теги, Тег | Статьи › Теги (› Тег) | чёрная полоса |
| Вопросы | Статьи › Вопросы | чёрная полоса |
| Вопрос | Статьи › Вопросы › **Техника** (самого вопроса нет) | внутри белой карточки |
| Техника | Статьи › Вопросы › Техника | чёрная полоса |
| Прошивки | Статьи › Прошивки | чёрная полоса |

| Прошивка | Статьи › Прошивки › **название** (марки и серии нет) | чёрная полоса |

Разметки для роботов нет нигде: `BreadcrumbList` отсутствует и в JSON-LD, и в microdata, на локальном и на боевом сайте. На странице прошивки есть
только `SoftwareApplication`. Робот видит `<nav><ol>` и больше ничего. На телефоне вдобавок список целиком скрыт (`hidden` на `md`), остаётся одна
ссылка «назад».

## 2. Проблемы

### Для пользователя и вёрстки

| № | Проблема | Серьёзность |
|---|---|---|
| Б1 | **Два разных места.** На списках крошки в чёрной полосе над заголовком, на статье и вопросе внутри белой карточки, на «О нас» и ленте их нет вообще. Человек и робот не находят их в одном и том же месте. | высокая |
| Б2 | **Разные правила последнего звена.** На списках последнее звено это текущая страница (без ссылки). На статье и вопросе последнее звено это родитель (категория, техника), самой страницы в цепочке нет. | высокая |
| Б3 | **Начало цепочки «Статьи» для всего.** Вопросы, прошивки, теги и личный кабинет показаны как разделы внутри «Статей». Это неверная иерархия: вопрос или прошивка не часть раздела статей. Раньше было «Главная», потом другая правка заменила его на «Статьи». | высокая |
| Б4 | Разная форма на ширине до 768 px: на списках одна ссылка назад, на статье такая же, но без сохранения контекста (какой раздел). | средняя |
| Б5 | Названия звеньев не совпадают с заголовками: звено «Прошивки», заголовок «Прошивки для бытовой техники»; «Теги» и «Теги статей»; «Категории» и «Категории статей». Для человека не ошибка, для разметки лучше совпадение. | низкая |
| Б6 | На странице прошивки в цепочке нет марки: у 5 343 из 10 499 прошивок поле `brand` пустое, а звено строится только если марка заполнена. Для заполненных нет и серии. | средняя |

### Для поисковиков

| № | Проблема | Серьёзность |
|---|---|---|
| С1 | **Нет `BreadcrumbList`.** Google и Яндекс строят «хлебные крошки» в сниппете выдачи по разметке; без неё сниппет показывает голый URL или угадывает путь. На сайте с 10 тысячами страниц прошивок это упущенный сниппет. | высокая |
| С2 | **Неверный корень цепочки** (Б3): робот увидит, что вопросы и прошивки лежат внутри «Статей», и так проиндексирует иерархию. | высокая |
| С3 | **Последнее звено без текущей страницы** на статье и вопросе: по рекомендации Google в цепочку входит и сама страница (последний элемент без ссылки допустим). Сейчас статья в собственной цепочке не названа. | средняя |
| С4 | Видимые крошки на телефоне скрыты, в mobile-first индексе они имеют меньший вес. Разметка JSON-LD решает это целиком. | средняя |
| С5 | Нет единой цепочки для страниц с несколькими путями: статья принадлежит одной категории, поэтому конфликта путей нет (это хорошо), но нужно закрепить правило «один путь на страницу». | справка |
| С6 | В цепочке нет названия сайта в `item` корня: корень ведёт на `/articles`, а сам `/` перенаправляет. Корнем должна быть страница, на которую можно сослаться напрямую. | средняя |

## 3. Что делать (предложение)

### 3.1. Одно место и один вид
Крошки всегда в **тонкой светлой полосе сразу под шапкой**, одним и тем же компонентом, на всех страницах кроме главной ленты и экранов входа.
Чёрная полоса остаётся только заголовком (h1). Тогда на любой странице крошки на одном и том же месте, и человек, и робот находят их без поиска.
Варианты, если полоса не нравится: A) оставить внутри чёрной полосы и перенести туда же крошки статьи и вопроса (тогда h1 статьи становится 24 px,
и статья теряет заголовок), B) полоса под шапкой (рекомендую).

### 3.2. Одно правило цепочки
1. Первое звено всегда **«Главная»** (`/articles`, то есть страница, на которой живёт лента; так было в старом дизайне).
2. Дальше раздел (Статьи не показывается как раздел, это и есть главная), дальше родитель, последнее звено **сама страница** без ссылки.
3. Один путь на страницу, без вариантов.

| Страница | Цепочка |
|---|---|
| Лента | нет (это корень) |
| Статья | Главная › {Категория} › {Название статьи} |
| Категория | Главная › {Категория}. Страница «Категории» удалена: она дублировала левое меню «Разделы», адрес `/categories` отдаёт 301 на `/articles`, из карты сайта убран |
| Теги / Тег | Главная › Теги (› {Тег}) |
| Вопросы / Вопрос | Главная › Вопросы (› {Техника} › {Название вопроса}) |
| Техника | Главная › Вопросы › {Техника} |
| Прошивки | Главная › Прошивки |
| Марка / Серия | Главная › Прошивки › {Марка} (› {Серия}) |
| Прошивка | Главная › Прошивки › [{Марка}] › [{Серия}] › {Название файла}, где марка и серия есть только если известны |
| О нас, Согласие | Главная › {Страница} |
| Личный кабинет, Подтверждение почты | Главная › {Страница} (закрыты от индексации, но вид единый) |

Длинные названия обрезаются только визуально (многоточие); в разметку идёт полное.

### 3.3. Разметка из тех же данных
Компонент крошек получает массив звеньев один раз и рисует и видимые крошки, и `<script type="application/ld+json">` с `BreadcrumbList`
(`position`, `name`, `item` как абсолютный URL; у последнего звена `item` текущей страницы). Так видимое и размеченное не могут разойтись.
Видимый список на телефоне показывать целиком в одну строку с прокруткой (а не прятать), чтобы совпадало с разметкой.

### 3.4. Прошивки без марки
Для 5 343 прошивок без марки цепочка короче (Главная › Прошивки › Название). Это честно. Заполнить марку у них можно командой `firmware:enrich`
(она уже есть в проекте), тогда они сами попадут в цепочку и на страницы марок. Это отдельная задача данных.

### 3.5. Проверка после правки
Скрипт обходит 16 типов страниц и сравнивает: положение в вёрстке, наличие `BreadcrumbList`, равенство видимых звеньев и разметки, последний
элемент равен h1 или названию страницы, первое звено «Главная». Внешние проверки (их нужно сделать вам, у меня нет доступа):
Яндекс Вебмастер, раздел «Структурированные данные», и Google Rich Results Test на двух-трёх адресах.

## 4. Что не входит
Сайтмап и каноникал не менялись. Заголовки `<title>` и мета-описания страниц не обсуждались (они в фазе 4 аудита). Разметка `Article`
для статей и `QAPage` для вопросов даёт свой сниппет, это отдельное решение.
